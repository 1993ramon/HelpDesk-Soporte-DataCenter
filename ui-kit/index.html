Actividad #5 - Design System

Componentes reutilizables para el sistema de gestión de incidentes.

Este archivo demuestra las piezas visuales principales del Help Desk: botones, formularios, tarjetas y etiquetas de prioridad. La implementación usa CSS3 puro, variables, modelo de cajas, selectores de estado y clases comunes para evitar código repetido.

1. Variables y paleta corporativa

Los colores, radios, sombras, espaciados y tipografía están centralizados en :root, lo que permite mantener una línea gráfica consistente en todo el proyecto.

2. Botones reutilizables

La clase base .btn concentra el tamaño, padding, radio y transición. Las variantes solo cambian color e intención, evitando duplicar estilos.

Los botones incluyen estados :hover, :focus-visible y :disabled para mejorar la interacción por mouse y teclado.

3. Formularios

Los campos de texto, listas desplegables y áreas de descripción usan bordes, padding y sombra de enfoque.

4. Tarjetas de tickets y badges

Las tarjetas usan box-shadow, bordes redondeados y una estructura flexible para presentar la información de incidentes. Los badges muestran prioridad Alta, Media y Baja.
